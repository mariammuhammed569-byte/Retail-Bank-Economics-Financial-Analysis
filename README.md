# Retail Bank – Economics & Financial Analysis 📊💰

An interactive Power BI dashboard designed to analyze retail banking data from financial, economic, customer, merchant, payment, and risk perspectives.

## 📌 Project Overview

This project transforms banking transaction data into meaningful business and economic insights using Power BI and DAX.

The analysis focuses on understanding transaction performance, tax contribution, revenue generation, customer behavior, merchant performance, payment channels, and financial indicators.

## 📊 Dashboard Sections

- Customer Analysis
- Merchant Analysis
- Payment Channel Analysis
- Card Analysis
- Fraud & Risk Analysis
- Economics & Financial Analysis
- Forecasting

## 💰 Economics & Financial Analysis

The economic analysis includes:

- Gross Transaction Value
- Net Transaction Value
- Total Tax
- Effective Tax Rate
- Tax-to-Revenue Ratio
- Tax Contribution by Customer Loyalty Tier
- Monthly Transaction Value & Tax Trends
- Financial performance indicators

## 🛠️ Tools & Technologies

- Power BI
- DAX
- Data Modeling
- Data Visualization
- Financial & Economic Analysis

## 🎯 Project Objective

The main objective is to transform raw banking transaction data into actionable financial and economic insights that can support better business decisions and performance evaluation.
